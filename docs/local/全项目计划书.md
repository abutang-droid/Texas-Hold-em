## 一、执行摘要

Texas Hold'em 是一款跨端（iOS / Android / Web）社交竞技德州扑克产品，采用**单向封闭筹码经济**。本项目目标是在 **58 周内**完成：

1. **前期调研与产品设计**（6 周）  
2. **全球英文区 App Store / Google Play 上架**（v1.1 公测）  
3. **真实 IAP 收款与私人场全开**  
4. **首年稳态运营**（自然量 → T1 买量验证 → 稳态）

### 1.1 四期方案一览

| 期次 | 时间 | 核心目标 | 付款 | 累计 |
|------|------|----------|------|------|
| **第零期** | W-6 – W-1 | 调研、Scope Matrix、Wireframe、**本计划书定稿** | **¥98,000** | ¥98,000 |
| **第一期** | W1 – W4 | 接场、设计规范、IAP/OAuth、Staging | **¥300,000** | ¥398,000 |
| **第二期** | W5 – W8 | 牌桌 UI、压测、商店提审 | **¥370,000** | ¥768,000 |
| **第三期** | W9 – W12 | 正式上线、终验、Hypercare | **¥242,000** | **¥1,010,000** |

### 1.2 关键判断

| 维度 | 结论 |
|------|------|
| 产品定位 | 社交竞技德州扑克，娱乐筹码，非真钱博彩 |
| 变现 | IAP 充值（主）+ 官方场 5% / 私人场 3% rake |
| 技术现状 | 核心玩法与私人场 **已完成**；缺口在原生 IAP、UI 落地、压测、上架 |
| 首发市场 | 全球英文区（English U.S. 主语言） |
| 私人场 | **公测即开**，强风控 + 后台熔断 |
| 首年 KPI（保守） | 注册 5–10 万 · MAU 8,000–15,000 · 付费率 3–5% |

> **Gate 规则：** 第零期《项目计划书》创始人签字 → 方可启动第一期 W1。

## 二、项目背景与目标

### 2.1 背景

- 产品 PRD v2.0 与经济模型已设计完成，代码仓库 `phase4-open-beta-2fc9` 约 **80%** 达到 v1.1 要求。  
- 当前移动端为**功能骨架**，距 PRD 拟物化视觉仍有差距；IAP 服务端验单已有，客户端需接原生 StoreKit / Play Billing。  
- 战略方向已锁定：**全球英文区**首发、**私人场公测即开**、**方案 A 筹码迁移**、美国不做 T1 买量。

### 2.2 项目目标（SMART）

| # | 目标 | 衡量标准 | 目标日期 |
|---|------|----------|----------|
| G1 | 完成前期调研与范围锁定 | Scope Matrix 签字 | W-3 |
| G2 | 完成拟物化 UI 设计 + 落地 | Figma 评审 + 核心路径视觉一致 | W8 |
| G3 | 全球英文区双端上架 | App Store + Google Play 可下载 | W9 |
| G4 | 真实 IAP 端到端到账 | 生产环境首笔充值成功 | W9 |
| G5 | 压测与容量达标 | 300 CCU 报告；P99 开局 ≤5s | W7 |
| G6 | 公测筹码迁移执行 | 方案 A 脚本执行；用户确认率 ≥95% | W9 前 |
| G7 | 软启动验证留存 | D7 留存 ≥12%；Crash-free ≥99.5% | W20 |
| G8 | T1 买量验证单位经济 | LTV/CPI ≥0.7 或按纪律停投 | W32 |

### 2.3 不在本项目范围（Won't）

- v1.5 功能（GTO Bot、好友、成就 CMS、多盲注）  
- v2.0 Web 支付（Stripe / USDC）  
- 美国专项合规律师（如需单独立项）  
- 用户买量预算（另计 ¥180,000/年）  
- 客服人力（仅含工具 SaaS）
