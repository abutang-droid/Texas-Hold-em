## 九、假设、除外与风险

### 9.1 报价假设

1. **Phase 0（W-6 – W-1）** 为执行前置条件；未完成则 W1 不启动  
2. 甲方提供 Apple / Google 开发者账号及 IAP 商品配置权限  
3. 代码基线以 `cursor/phase4-open-beta-2fc9` 为准，无重大架构重写  
4. 首发 **全球英文区**，UI 主语言 en-US，保留 zh-CN  
5. 私人场 **公测即开**（与现行战略一致）  
6. 筹码迁移采用 **方案 A**（清零 + 赠 100）  
7. 设计修订每阶段 **≤2 轮**，超出按 ¥3,000 / 轮另计  

### 9.2 不含范围

- 用户买量、KOL、社群运营  
- 客服人力（仅含 Zendesk 等工具费）  
- IAP / 商店流水抽成（15% – 30%）  
- 美国专项合规律师（如需单独立项）  
- v1.5 / v2.0 新功能  
- 多区域多活、K8s 集群（首年单区域足够）
