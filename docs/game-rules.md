# 6-max 现金桌规则（现行实现）

对照 Web 德州 MVP 技术规格 V1.0，按本项目 **6 人桌** 校正。  
规则源：`packages/poker-engine`（唯一裁决）+ `apps/room` 执行。

## 桌子

| 项 | 值 |
|---|---|
| 人数 | **2–6**（6-max） |
| 游戏 | No-Limit Texas Hold'em 现金桌 |
| 官方盲注 | **1 / 2** |
| 官方带入 | 上限 **100**（50 BB；下限建议 40） |
| 私人场 | 房主配盲注 / 带入上限；无 Bot |
| 抽水 | 官方 5% / 私人 3%；没翻牌不抽 |
| 思考时间 | **20 秒** + **60 秒 Time Bank** |
| 局间 | 3 秒 |

规格原文 9 人桌、SB=10/BB=20 不采用（会打乱现有 100 筹码经济）。

## 盲注与先后手

**3–6 人**

- SB = Button 左手第一家，BB = 再左手一家
- 翻前：BB 左手（UTG）先动
- 翻后：Button 左手先动

**2 人（Heads-up）**

- Button **下小盲**，另一人下大盲
- 翻前：Button/SB 先动
- 翻后：BB 先动

盲注由服务器强制下，不是玩家 Action。

## 发牌

- 底牌：从 Button 左手起，每人一张，绕两圈
- 翻牌 / 转 / 河：先 **burn 1** 再发

## 下注

- 无限注。`currentBet == 0` 时为 Bet，否则 Raise
- 最小加注幅度 = 上一手 **完整加注** 的额度；开局为 1 BB
- All-in 是 Bet / Call / Raise 把剩余筹码推完，不是独立规则
- **短 All-in**（加注幅度 < 最小加注）：不能重新打开已经行动过的人的 Raise 权，只可跟或弃
- 仅剩一人未弃：直接给池，不摊牌
- 未弃牌者都 All-in：把公共牌发完再摊牌（runout）

## 边池与平局

- 按投入分层动态边池；弃牌者的钱入池但不能赢
- 每个池独立比牌
- 平分后余下的 1 筹码：从 **Button 左手起顺时针** 给第一个赢家

## 牌力

高牌 < 一对 < 两对 < 三条 < 顺子（A-2-3-4-5 为 5 高）< 同花 < 葫芦 < 四条 < 同花顺（皇家同花顺为 A 高同花顺）

从 2 底牌 + 5 公共牌取最佳 5 张。

## 超时

- 20 秒内未行动则消耗 Time Bank
- Time Bank 用尽：能过则过，否则弃
- 倒计时以服务器 `actionDeadline` 为准

## 公共场进出

1. **进场先观战**：加入官方桌不占座、不买入。桌上已有最多 5 个机器人在打进行中的牌局，留 1 个空位。
2. **点空位坐下**：买入后入座。若本手已开始，本手观战，**下一手**才发牌。
3. **起身**：离开座位，筹码兑回余额，继续观战。若本手已投入底池，先弃牌，本手结束后才离座。
4. **离场**：离开房间。中途离场同样等本手结束再兑筹码，避免底池被抽走。

私人场仍是进房即入座。

## 部署后桌测

Room health `"version":"0.5.1"` 表示本规则已上 Staging。桌测：

1. 两人桌：Button 下 **1**，另一人下 **2**；翻前 Button 先动
2. 行动条约 **20 秒**（不是 15 秒）
3. 最多 6 个座位
4. 全下后公共牌会发完再摊牌
5. 官方场：进房先观战，点空位坐下；中途可起身 / 离场
