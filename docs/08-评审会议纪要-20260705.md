## 四、v1.0 MVP 范围（会后修订）

### 包含

- 官方场（**9 人桌**、1/2 盲注、动态 cap、5% rake）
- **私人定制场**（100 筹码权限、3% rake、房主管理、Re-buy 审批）
- 用户系统（Apple/Google + 游客）
- **模拟支付商城**
- **规则型 Bot** 补位
- IP/设备互斥、断线重连
- 后台最小集

### 不包含（v1.5+）

- 真实 IAP / Google Play / USDC 支付
- GTO Bot 引擎（Python gRPC）
- 好友 / 排行榜 / 成就
- 对局回放 UI
- 运营活动 CMS

## 五、模拟支付规格（会后新增）

```
POST /api/v1/shop/mock-recharge
Body: { "amount": 1000, "requestId": "uuid" }
```

- 跳过外部支付网关，直接写 `recharge_orders` + `chip_transactions`
- 仍执行单日 50,000 充值上限校验
- 生产环境该接口返回 403
