## 二、各版本详细范围

### v1.0 内测（Closed Beta）

**目标**：验证官方场经济循环、Bot 补位、基础留存

| 模块 | 范围 | 验收标准 |
|---|---|---|
| 官方场 | 9 人桌、1/2 盲注、动态 cap、5% rake | 完整一局可结算 |
| Bot | 规则型、5 秒补位、满 9 人退场 | P99 开局 ≤5s |
| 用户 | 游客 + Apple/Google 登录 | JWT 可用 |
| 支付 | **模拟支付**（`PAYMENT_MODE=mock`） | 即时到账 + 日限额 |
| 新用户 | 注册送 **100 筹码** + 3 步引导 | 新用户可完成首局 |
| 留存 | 简易等级（Lv+EXP）+ 本周盈利 Top10 | 大厅可见 |
| 风控 | IP/设备互斥（官方场） | 同 IP 拒绝同桌 |
| 断线 | Snapshot 重连 | 重连恢复一致 |
| 后台 | 用户查询/封禁/调账 | 运营可处理客诉 |
| 聊天 | 官方场 Emoji 快捷语 | 8–12 个预设 |

**不包含**：私人场、真实 IAP、好友、完整排行榜、成就、回放 UI

---

### v1.0.5 扩量内测（Expanded Beta）

**目标**：验证私人场组局率与合规流程

| 模块 | 新增/变更 | 验收标准 |
|---|---|---|
| 私人场 | 开房权限 100 筹码、3% rake、2–9 人 | 完整私房局 |
| 组局 UX | 房间号、分享链接、复制邀请文案 | 分享后可加入 |
| 私人场管理 | 踢人、暂停、Re-buy（60s 超时）、解散 ≥2/3 | 房主流程可用 |
| 2 人局限制 | 房主需官方场 ≥10 局 | 限制生效 |
| 举报 | 牌桌举报 → 后台工单 | 可提交并查看 |
| 风控 | chip dumping 基础规则 | 触发告警入库 |
| 后台 | 私人场全局开关 + 经济看板 | 运营可见 |

**简化项（相对原 PRD）**：暂无解散投票全员同意；房主可单方解散（需牌局结束）

---

### v1.1 公测（Open Beta / Soft Launch）

**目标**：商业化与运营体系就绪

| 模块 | 新增 | 验收标准 |
|---|---|---|
| 支付 | Apple IAP + Google Play | 沙盒/生产到账 |
| 内测迁移 | 筹码清档或公告折算规则 | 用户确认 |
| 排行榜 | 完整双榜（盈利 + 单局最高） | 每 10 分钟刷新 |
| 后台 | 运营三板斧完整 | 经济看板/用户详情/配置 |
| 合规 | 18+ 自声明、Responsible Gaming 入口 | 商店审核通过 |
| 破产优化 | 首充赠送（运营池） | 活动可配置 |

## 五、风险与缓解

| 风险 | 缓解 |
