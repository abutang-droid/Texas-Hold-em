## 一、架构图

```
Client → LB → API Server  → PostgreSQL / Redis
Client → LB → Room Server → Redis (+ PostgreSQL 异步结算)
              Room Server → RuleBot (v1.0 进程内)
              Room Server → Bot Engine gRPC (v1.5+)
```

---

## 二、数据层（PostgreSQL 16）

| 组件 | 选型 | 说明 |
|---|---|---|
| 主数据库 | **PostgreSQL 16** | 用户、筹码流水、手牌历史 |
| 缓存 | Redis 7 | 房间状态、Session、排行榜 |
| ORM/查询 | Prisma 或 node-pg | 待定 |
| 迁移 | Flyway / node-pg-migrate | `infra/migrations/` |

### 持久化策略

```
对局中     → Redis only
END_HAND   → hand_histories + rake 流水（异步）
CASH_OUT   → PostgreSQL 事务（chip_transactions + users）
```

### 与 MySQL 方案差异

| 项 | PostgreSQL |
|---|---|
| JSON | JSONB（可索引） |
| 整数 | BIGINT + CHECK |
| 时间 | TIMESTAMPTZ |
| 分区 | 原生 PARTITION BY RANGE |

完整 Schema 见 `03-数据库设计完整版.md`。
