# 德州扑克 · 项目设计规范

版本：v1 · 2026-08-31  
状态：**当前客户端视觉 SSOT**  
适用范围：Expo / React Native 客户端（大厅、登录、牌桌、商城、设置）及与之配套的共享 Design Tokens。

本规范根据《德州扑克（Hold'em）· 极简在线设计规范（v2 在线版）》整理，并按本仓库的真实产品约束落地：

- 官方 6 人桌（`maxPlayers = 6`），椭圆座位，荷官固定顶中
- 默认旁观 → 入座 → 站起 / 离桌
- 发牌从荷官飞出、公共牌翻牌前不占位、摊牌逐步结算
- 技术栈为 React Native，不是 HTML `#phone` 画板；原则与 token 对齐规范，实现用 RN 组件

---

## 1. 设计原则

1. **留白优先**：界面以浅灰底 + 白卡片为主，信息分区靠间距，不靠描边堆砌。
2. **单一强调色**：鼠尾草绿 `#2E7D63` 只用于「当前行动 / 主按钮 / 底池与下注高亮」。
3. **低对比正文**：主文字 `#17191C`，次要文字 `#6B7280`，禁止大面积纯黑。
4. **字重分层**：标题 SemiBold / ExtraBold，正文 Regular，数字 SemiBold。
5. **触控优先**：可点区域 ≥ 44×44；主按钮最小高度 **52**。
6. **荷官顶中**：荷官是发牌起点与视觉锚点，不是装饰人像。
7. **不做赌场皮肤**：不用紫渐变、不用 emoji 当系统图标、不用写实荷官、不用传统深绿椭圆桌。

本仓库旧版「深夜墨绿 + 金色」已退役。金色 `#C9A227` 不再作为品牌色。

## 3. 信息架构与页面骨架

自上而下（牌桌）：

1. **顶栏**：返回 · 房间标题（`6 人 · 盲注`）· 设置
2. **荷官区**：圆形头像 + 状态胶囊（等待 / 发牌中 / 亮牌中）
3. **对手座位**：沿椭圆分布，避开顶中荷官与底中自己
4. **公共牌 + 底池**：桌心；翻牌前不放三张空牌位
5. **自己手牌 + 行动条**：底部固定；主按钮 52 高

大厅 / 登录 / 商城 / 设置沿用同一底色与白卡片，不另起深色皮肤。

---

## 4. 荷官

- 形态：圆形头像（「荷」字或极简筹码堆），**不是**写实人物。
- 位置：桌面顶中，发牌飞出的起点。
- 状态胶囊：`等待` / `发牌中…` / `亮牌中`。
- 发牌中：头像外圈用 `--accent` 细环。
- 禁止：帽子、领结、写实面部、金色光晕。

---

## 5. 座位

- 容器：白底、圆角 14、轻阴影。
- 庄家 D：`--accent` 底 + 白字小圆。
- 筹码：次要色数字，不用金色。
- 下注：`--accent-soft` 胶囊 + `--accent` 数字。
- 当前行动：`--accent` 描边 + `--accent-soft` 底。
- 弃牌：整体透明度 45%。
- 空座：虚线边 + 「入座」；旁观可点。
- 自己座位：可与手牌区合并，避免桌面上再叠一块重复座位卡。

---

## 6. 扑克牌

| 尺寸 | 宽×高 | 用途 |
| --- | --- | --- |
| xs | 26×36 | 对手牌背 |
| sm | 46×64 | 公共牌 |
| lg | 62×88 | 自己手牌 |

牌面：

- 白底、细线 `#E6E8EB`、圆角 8
- **左上角只放点数**（无花色角标）
- **正中放大花色**
- 不画右下角倒置索引
- 红花色 `#C23B3B`，黑花色 `#17191C`

牌背：

- 浅灰 `#E9ECF0`
- 细描边
- 中心旋转菱形线框（几何，不是赌场花纹）

摊牌：有竞争才亮对手手牌；单人赢（全弃）保持牌背。

---

## 7. 底池、计时、结算

- 底池：白卡片 + 鼠尾草绿数字，不用金色大字。
- 边池：同一卡片内次要色说明。
- 行动计时：圆环 / 数字用 `--accent`；与筹码色区分开。
- 结算：逐步展示（谁赢 → 主池 / 边池 → 未跟注退还）；文案用 ink / muted，金额用 accent。
- 飞筹码：浅灰筹码，轨迹克制，不做金色粒子。

---

## 8. 按钮与表单

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `--accent` 底 + **白字** + 圆角 14 + 高 52 |
| 次按钮 | 白底 + ink 字 + `--line` 边 |
| 弃牌 | 白底 + `--warn` 字与边 |
| 跟注 / 加注 | 主按钮样式 |
| 禁用 | 透明度 45%，不可点 |

输入框：白底、`--line` 边、圆角 10、高 ≥ 44。  
弹层：白底、圆角 18、轻阴影，无暗色木纹。

---

## 9. 动效

- 时长：飞牌 / 飞筹码 280–420ms，ease-out。
- 发牌：从荷官中心飞到目标座位或公共牌位。
- 翻牌：不要在翻牌前预留三张空槽。
- 禁止：弹性夸张弹跳、屏幕闪金、粒子爆炸。

---

## 10. 无障碍与工程约束

- 主操作对比度：绿底白字；正文 ink on `--bg`。
- 可点热区 ≥ 44px；站起 / 离桌等桌面小按钮按现有热区放大，不得小于 44。
- 中英文案走 `locales`，视觉层不写死房间玩法数字。
- Token 变更必须改 `colors.json` + `theme/index.ts`，禁止在页面里新增长期硬编码色。
- 本规范不改变协议与房间逻辑；UI 重构不得回退旁观 / 入座 / 站起 / 逐步结算。

---

## 11. 明确禁止

- 紫蓝渐变、金色标题、霓虹描边
- Emoji 充当系统图标（牌桌内表情互动条除外，且需收敛为次要控件）
- 写实荷官、深绿椭圆毡面、木纹桌沿
- 牌面四角重复索引、拟物赌场牌背
- 主按钮深色字（旧金色按钮的深字必须改为白字）
