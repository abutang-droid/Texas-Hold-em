## Phase 1：基础设施与核心引擎

**目标**：可独立运行的扑克引擎 + 数据层 + 项目骨架

### 1.1 工程初始化

| 任务 | 产出 |
|---|---|
| Monorepo 搭建（pnpm workspace） | `apps/mobile`, `apps/api`, `apps/room`, `packages/shared` |
| RN Expo 项目初始化 | 空白大厅 + 导航 |
| NestJS api + room 项目 | 健康检查接口 |
| Docker Compose 本地环境 | MySQL + Redis + 服务联调 |
| Flyway/Liquibase migration | 核心表 DDL |
| ESLint/Prettier/CI 骨架 | GitHub Actions lint |

### 1.2 扑克核心引擎（`packages/poker-engine`）

| 任务 | 验收标准 |
|---|---|
| 牌组洗牌（CSPRNG） | Fisher-Yates + crypto.randomBytes |
| 手牌评估（7 选 5） | 覆盖所有牌型 |
| 边池算法 | ≥5 个单元测试场景 |
| 抽水计算 | no-flop-no-drop + floor |
| 行动合法性校验 | fold/check/call/raise/all-in/min-raise |
| XState 状态机 | PRE_FLOP → … → END_HAND |
| **规则型 Bot 模块** | 同步决策 P99 <50ms |

### 1.3 数据层

| 任务 | 验收标准 |
|---|---|
| users + chip_transactions + private_rooms migration | 本地可 migrate |
| Redis room state 读写封装 | JSON 序列化 + 类型安全 |
| 带入/离桌事务模板 | MySQL 事务 + Redis lock 单测 |

**Phase 1 交付物**：
- [ ] poker-engine 测试覆盖率 ≥90%
- [ ] CLI 模拟 9 人桌完整一手牌
- [ ] Docker Compose 一键启动

## Phase 2：联网对局（官方场 + 私人场骨架）

**目标**：客户端可完成官方场与私人场联网对局

### 2.1 Room Server

| 任务 | 验收标准 |
|---|---|
| Socket.io + JWT 鉴权 | 未授权拒绝 |
| join_room / player_action | 符合 WS 协议 |
| room_state_sync（9 座） | 重连一致 |
| 15 秒倒计时 + 超时 Sit Out | 2 次超时生效 |
| IP/设备互斥 | 同 IP 拒绝 |
| 动态 buy-in cap | 服务端计算 |
| END_HAND → hand_histories | 异步写入 |
| **私人场状态扩展** | PAUSED、房主 admin 事件 |

### 2.2 Match Service

| 任务 | 验收标准 |
|---|---|
| 快速开始 API | 优先 ≥2 真实玩家桌 |
| 5 秒 Bot 计时器 | <3 人补至 3 人 |
| Bot 退场 | 满 **9** 人下局 Bot 离开 |
| 规则 Bot 集成 | 进程内调用，拟人延迟 |

### 2.3 客户端

| 任务 | 验收标准 |
|---|---|
| **9 座**拟物化牌桌 UI | 椭圆布局 |
| WS 连接 + 断线重连 | Snapshot 恢复 |
| 操作面板 | fold/check/call/raise/all-in |
| 大厅 + 快速开始 | 一键进桌 |
| 私人场入口（骨架） | 创建/加入房间号 |

**Phase 2 交付物**：
- [ ] 内测包可完成官方场 9 人桌对局（含 Bot）
- [ ] 私人场可建房、加入、完成对局（无 Bot）
