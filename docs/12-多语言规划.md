## 一、目标与范围

### 1.1 目标

- v1.0 内测起支持 **中文 / 英语** 双语，覆盖全部系统 UI
- 用户可在应用内切换语言，切换后即时生效（无需重启）
- 为 v1.5+ 扩展更多语言预留架构

### 1.2 翻译范围

| 类别 | 首期翻译 | 说明 |
|---|---|---|
| 系统 UI 文案 | ✅ | 按钮、标签、提示、错误信息 |
| 合规声明 | ✅ | 启动页、商城、牌桌 |
| 推送通知 | ✅ | |
| 邮件模板 | ✅ | 客服、验证码 |
| 运营活动文案 | ✅ | 后台配置多语言字段 |
| 用户生成内容 | ❌ | 昵称、聊天不翻译 |
| 手牌/牌型 | ✅ | 使用 i18n key（如 `HAND.ONE_PAIR`） |
| 数字/筹码 | 格式化 | 见 §四 |

## 二、语言与 Locale

### 2.1 支持列表（v1.0）

| Code | 语言 | 默认 | 备注 |
|---|---|---|---|
| `zh-CN` | 简体中文 | ✅ 系统中文时默认 | 大陆用语 |
| `en-US` | 英语（美国） | ✅ 系统非中文时默认 | 国际用户 |

### 2.2 语言检测优先级

```
1. 用户手动设置（持久化到 users.preferred_locale）
2. 设备系统语言（若在支持列表内）
3. 回退默认：en-US
```

### 2.3 未来扩展（v1.5+）

| Code | 语言 | 优先级 |
|---|---|---|
| `zh-TW` | 繁体中文 | P2 |
| `ja-JP` | 日语 | P3 |
| `ko-KR` | 韩语 | P3 |
| `es-ES` | 西班牙语 | P3 |

## 三、技术方案

### 3.1 客户端（React Native / Expo）

| 项 | 方案 |
|---|---|
| 框架 | **i18next** + `react-i18next` + `expo-localization` |
| 资源文件 | `apps/mobile/src/locales/{zh-CN,en-US}.json` |
| 命名空间 | `common`, `lobby`, `game`, `shop`, `settings`, `errors` |
| Key 规范 | `namespace.section.key`，如 `game.action.fold` |

**示例**：

```json
// zh-CN.json
{
  "game": {
    "action": {
      "fold": "弃牌",
      "check": "过牌",
      "call": "跟注 {{amount}}",
      "raise": "加注",
      "allIn": "全押"
    },
    "pot": "底池"
  }
}
```

```json
// en-US.json
{
  "game": {
    "action": {
      "fold": "Fold",
      "check": "Check",
      "call": "Call {{amount}}",
      "raise": "Raise",
      "allIn": "All In"
    },
    "pot": "Pot"
  }
}
```

### 3.2 服务端（API / Room Server）

| 项 | 方案 |
|---|---|
| 协议 | 请求头 `Accept-Language: zh-CN` 或 `en-US` |
| 错误信息 | 返回 `messageKey` + `message`（已翻译） |
| 邮件/推送 | 按 `users.preferred_locale` 选模板 |

**错误响应示例**：

```json
{
  "code": 40001,
  "messageKey": "errors.insufficient_chips",
  "message": "Insufficient chips",
  "requestId": "uuid"
}
```

### 3.3 数据库

```sql
-- users 表增加
preferred_locale VARCHAR(10) NOT NULL DEFAULT 'en-US'
```

合法值：`zh-CN` | `en-US`（v1.0）

### 3.4 后台 CMS（v1.1）

- 运营活动标题/描述：`title_i18n JSONB` → `{ "zh-CN": "...", "en-US": "..." }`
- 系统公告同理

## 四、本地化格式（L10n）

| 类型 | zh-CN | en-US |
|---|---|---|
| 数字千分位 | 1,234 | 1,234 |
| 筹码显示 | `1,234 筹码` | `1,234 chips` |
| 日期 | 2026年7月8日 | Jul 8, 2026 |
| 时间 | 14:30 | 2:30 PM |
| 相对时间 | 3 分钟前 | 3 minutes ago |
| 货币（充值 UI） | $ 符号 + 金额 | 同左 |

使用：
- 客户端：`Intl.NumberFormat` / `dayjs` + locale plugin
- 服务端：按 locale 格式化日志展示（后台）

## 五、文案管理流程

```
1. 产品撰写中文基准文案（zh-CN 为 source of truth）
2. 翻译为 en-US（人工或 CAT 工具）
3. PR 审核：key 命名、占位符一致
4. CI 检查：各 locale 文件 key 集合一致（i18n-key-check）
5. 发布：随版本打包
```

### 5.1 禁止硬编码

- ESLint 规则：`no-literal-string`（UI 层）
- Code Review 检查项

### 5.2 占位符规范

- 使用 `{{variable}}`，禁止拼接字符串
- 复数：`{{count}}` + 英文复数规则（i18next plural）
